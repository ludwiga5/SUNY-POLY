# SUNY Polytechnic University Coursework

A collection of coursework and projects from computer science courses at SUNY Polytechnic University.

## Courses

### CS108 - Introduction to Programming
Topics Covered:
- Basic C syntax and control flow
- Functions and modular design
- Arrays and data structures
- String manipulation
- Linked lists and recursion

### CS220 - Computer Organization / Architecture
Topics Covered:
- Circuits & Circuit Diagrams
- Binary Operations
- Binary Manipulation
- CPU & ALU
- **HW1 Section-1**: Black and white image manipulation (PGM format)
- **HW1 Section-2**: Color image processing (PPM format)
- **HW3**: Digital logic circuits and ALU simulation in C
- Labs covering C compilation pipeline and review

### CS240 - Data Structures & Algorithms
Topics Covered:
- Basic C++ syntax and OOP concepts
- Memory allocation and pointers
- Dynamic arrays and data structures
- Classes and object design
- Linked lists and string handling
- Queues and call center simulation
- Vectors and Login Log example
- Recursion

### CS249 - Object Oriented Programming
Topics Covered:
- Java Overview
- Objects & Classes
- OOP
- Inheritance & Polymorphism
- Text/IO-Exception Handling
- Interfaces & Abstract Classes
- Java FX Basics
- Design Patterns
- Test-Driven Development
- Event-Driven Classes

### CS330 - Operating Systems & Networking
Topics Covered:
- Computer Hardware Organization
- The BIOS and Boot Process
- Multiprogramming and Multithreading
- Process
- Thread
- Scheduling
- Memory Management
- Interprocess Communication/Synchronization
- Deadlock and Starvation
- Operating System Categories
- Networking: TCP/IP
- Network Programming
- Network Services
- Network Analysis
- Network Analysis

### CS350 - Database Systems
Topics Covered: 
- Database requirements
- ER modeling
- Relational modeling
- Database constraints
- Update anomalies
- Normalization
- SQL
- The database front-end
- Data quality
- Data warehousing concepts
- Dimensional modeling (star schemas)
- Data warehouse/data mart modeling approaches
